🔒 Privacy, security & storage

🔑 Tumhari API keys sirf isi browser mein (localStorage) save hoti hain. Hamara koi server nahi hai. Par dhyaan rakho: browser storage poori tarah "secure" nahi hota. Is phone ko use karne wala ya koi bura browser extension key dekh sakta hai. Isliye: key kisi ko mat do, GitHub pe mat daalo, aur Google AI Studio mein key ko sirf "Generative Language API" tak restrict kar do. Key leak ho jaye to delete karke nayi bana lo.

Off karoge to key sirf tab tak rahegi jab tak ye tab khula hai (band karte hi hat jaayegi, har baar dobara paste karni hogi). Shared ya school ke phone/computer pe off rakho. Sabse safe tareeka: apna server (Settings → AI → "Apna server").

Project S ek personal AI assistant aur tutor hai jo Hindi, Hinglish aur English mein baat karta hai. Ye ek hi web page hai: koi install nahi, koi server nahi.

Kya kya kar sakta hai

  • 💬 Baat-cheet, padhai, maths, coding, writing aur research
  • 🧮 SymPy maths engine: exact answers aur graphs
  • 🌐 Web search, source links ke saath
  • 📷 Photos, 📄 PDF, Word, TXT aur Markdown samajhna
  • 🎤 Voice typing, 🔊 jawab bol ke sunana, 🗣 voice chat
  • 📚 Study mode: quiz, flashcards, notes · 🧠 Memory · ⭐ Library

AI providers

Google Gemini (free key), OpenRouter (free models) aur Anthropic Claude (paid). Tum apni key daalte ho; S seedha usi provider se baat karta hai.

Privacy

Chats, memory, Library aur keys sirf tumhare browser mein rehte hain. Hum koi data store nahi karte. Sawaal jawab banane ke liye sirf tumhare chune hue AI provider ke paas jaata hai.
